# 03 — MVP Scope

## In scope

- One camera.
- One Seeed Studio XIAO ESP32-S3 camera-capable board / Sense variant.
- One local Windows laptop/server.
- Local AI inference.
- One real kitchen mapping video.
- One persistent Kitchen Knowledge Graph.
- One simplified tea-preparation task.
- Laptop speaker voice guidance.

## Deferred

- Haptics.
- Wearable product enclosure.
- Multiple cameras.
- SLAM.
- 3D reconstruction.
- Robotics.
- Cloud GPU.
- Neo4j or production database infrastructure.
- Production deployment.
- Safety certification.

## Implementation priority

Optimize for a working, inspectable, recoverable end-to-end demo over completeness. Prefer deterministic code and simple APIs. Avoid heavyweight packages or large model downloads until hardware resources and model compatibility are verified.
