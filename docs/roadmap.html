Kitchen Memory Assistant — Live Development Roadmap

Local-only hackathon MVP: learn a kitchen from one narrated walkthrough video, build a Kitchen Knowledge Graph, and guide a safe tea task through laptop speaker audio.

Last updated: 2026-10-04

Current phase

Laptop AI MVP — Perception, Memory, Query

ESP32 camera is live, and a mobile-phone camera mapping mode has been added for higher-quality kitchen visuals. Current focus is local perception, kitchen graph memory, deterministic Q&A, and live assistant interaction.

Overall progress

50%: HF CLI verified, CUDA stack verified, 20 keyframes extracted, SmolVLM2-500M tested on one keyframe, faster-whisper transcript generated, graph/query created, ESP32 live feed working, and mobile camera mapping endpoint/page added.

Next immediate milestone

Use mobile camera mapping from /mobile/ to capture high-quality kitchen frames locally, then select frames for graph improvement or approved VLM analysis.

Latest cycle: low-latency video and voice console

  • Done Phone video to dashboard over WebRTC peer-to-peer on the LAN (30 fps, hardware encoder). Server only relays signaling at /ws/signal; JPEG at 2 fps continues for the VLM.
  • Done Dashboard redesigned as a voice-first console: talk button and hands-free mode (/api/voice/turn), typed chat, kitchen memory with walkthrough evidence frames, tea step progress, collapsible diagnostics.
  • Done Answer authority order: safety intents (stop, repeat), then kitchen graph, then Nemotron. Replies are spoken in the background so text appears immediately.
  • Done Kitchen graph rebuilt from a Claude vision review of 52 walkthrough frames plus narration (scripts/build_graph_claude_vision.py): 21 objects, left-to-right counter order, per-object evidence frames, coffee routine. The walkthrough shows coffee, not tea.
